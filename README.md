# Фото-отчёт о проделанной работе
## Проект: LinuxTrainer — веб-тренажёр командной строки Linux

---

### 1. Страница входа (Login)
**URL:** /login
**Описание:** Форма авторизации с полями логин/пароль. Cookie-аутентификация, хеширование паролей.
**Скриншот:** [вставить скриншот]

---

### 2. Профиль студента
**URL:** /profile
**Описание:** Отображает аватар, имя, роль. Круговой прогресс выполнения заданий (% и количество). Средний балл. Таблица детализации по каждому заданию с баллами и статусами.
**Скриншот:** [вставить скриншот]

---

### 3. Список заданий (квесты)
**URL:** /profile/quests
**Описание:** Карточки заданий с иконками статуса (замок, play, песочные часы, галочка). Последовательная разблокировка — следующее задание доступно только после одобрения предыдущего преподавателем.
**Скриншот:** [вставить скриншот]

---

### 4. Выполнение задания
**URL:** /profile/quests/{id}
**Описание:** Левая панель — описание задания, вопрос, поле ответа. Правая панель — терминал-песочница с изолированной файловой системой для данного квеста. Студент исследует ФС командами и вводит ответ.
**Скриншот:** [вставить скриншот]

---

### 5. Эмулятор терминала (свободный режим)
**URL:** /profile/terminal
**Описание:** Полноценный эмулятор Ubuntu 22.04 с виртуальной файловой системой. Поддержка команд: ls, cd, pwd, cat, echo (>, >>), mkdir, touch, rm, man, history, clear, whoami, uname. История команд (стрелки вверх/вниз). Кнопка «Сбросить» для возврата ФС в исходное состояние.
**Скриншот:** [вставить скриншот]

---

### 6. Настройки профиля
**URL:** /profile/settings
**Описание:** Смена отображаемого имени, загрузка аватара (отправляется на модерацию преподавателю).
**Скриншот:** [вставить скриншот]

---

### 7. Панель преподавателя — Студенты
**URL:** /teacher/students
**Описание:** Список студентов с их прогрессом и оценками.
**Скриншот:** [вставить скриншот]

---

### 8. Панель преподавателя — Управление заданиями
**URL:** /teacher/quests
**Описание:** Таблица всех квестов (порядок, название, вопрос, ожидаемый ответ). Кнопки создания, редактирования и удаления. Форма с полями: название, сложность, описание, вопрос, ожидаемый ответ.
**Скриншот:** [вставить скриншот]

---

### 9. Панель преподавателя — Модерация
**URL:** /teacher/reviews
**Описание:** Две вкладки: «Ответы» и «Аватары». В ответах — карточки с данными студента, вопросом, ожидаемым и фактическим ответом. Преподаватель выставляет балл (0-5) и одобряет или отклоняет с комментарием.
**Скриншот:** [вставить скриншот]

---

### 10. Панель администратора — Пользователи
**URL:** /admin/users
**Описание:** Таблица пользователей (ID, логин, имя, роль). Смена роли через выпадающий список. Кнопки: сброс пароля, удаление. Форма создания нового пользователя.
**Скриншот:** [вставить скриншот]

---

## Технические характеристики

| Параметр | Значение |
|----------|----------|
| Платформа | .NET 9 |
| Фреймворк | Blazor (Server + WebAssembly) |
| UI-библиотека | MudBlazor |
| СУБД | SQLite + Entity Framework Core |
| Аутентификация | Cookie-based |
| Тема | Тёмная (Material Design) |
| Порт | 5009 |

---

## Реализованный функционал

- Эмулятор терминала Linux с виртуальной файловой системой
- Система квестов с последовательной разблокировкой
- Три роли: Студент, Преподаватель, Администратор
- Модерация ответов и аватаров преподавателем
- Профиль с прогрессом и средним баллом
- CRUD заданий и пользователей
- Адаптивный интерфейс с тёмной темой
